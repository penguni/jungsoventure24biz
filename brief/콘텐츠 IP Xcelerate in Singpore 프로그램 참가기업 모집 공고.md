# 콘텐츠 IP Xcelerate in Singpore 프로그램 참가기업 모집 공고

## 사업개요

한국콘텐츠진흥원 싱가포르 비즈니스센터에서 콘텐츠 IP의 해외시장진출을 지원하기 위해서 콘텐츠 IP Xcelerate in Singapore를 운영할 예정으로 참가기업을 8월
27일부터 상시 선착순 모집하오니 많은 관심과 참여를 부탁드립니다.

☞ 싱가포르 거점으로 해외진출, 투자유치를 희망하는 콘텐츠기업(대기업, 중견기업, 중소기업, 벤처기업 등 법인사업자)

- 콘텐츠 IP를 통해 해외진출, 투자유치 하고자 하는 기업이나 콘텐츠 IP에 테크, 혁신 요소
를 접목해 비즈니스를 하는 기업

- 분야 : 방송, 영화, 애니메이션, 음악, 웹툰, 게임 등 콘텐츠 전 분야

☞ 온라인 프로그램, 현지 프로그램 지원
